         <h2 id="introduction">Introduction to HTML:</h2>
        <h3>What is HTML?</h3>
        <p>HTML (HyperText Markup Language) is the standard markup language for creating web pages and web applications.<br> It describes the structure of a web page using markup.</p>
        <p>HTML consists of a series of elements that tell the browser how to display the content. These elements form the<br> building blocks of web pages.</p>
        <h3>Explanation of Elements</h3>
        <ul>
            <li><strong>!DOCTYPE html</strong> - Defines this document as HTML5</li>
            <li><strong>html</strong>- The root element of the HTML page</li>
            <li><strong>head</strong>- Contains meta information about the document</li>
            <li><strong>title</strong>-  Sets the title of the document (shown in the browser tab)</li>
            <li><strong>body</strong>- Contains the visible page content</li>
        </ul>

        <h2 id="introduction1">Introduction to CSS</h2>
        <h3>What is CSS?</h3>
        <p>CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML. <br>CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.</p>
        <p>CSS is one of the core technologies of the World Wide Web, alongside HTML and JavaScript. It controls the visual appearance <br>of web pages, including colors, fonts, layouts, and responsive behaviors.</p>
        <h3>How CSS Works</h3>
        <p>CSS works by associating rules with HTML elements. These rules determine how the content of specified elements should be displayed.<br> A CSS rule contains two parts: a selector and a declaration.</p>
        <ul>
            <li><strong>Selector</strong>- Points to the HTML element you want to style</li>
            <li><strong>Declaration</strong>- The style you want to apply to the selected element</li>
            <li><strong>Property</strong>- The aspect of the element you want to change (color, font-size, etc.)</li>
            <li><strong>Value</strong>- The setting you want to assign to the property</li>
        </ul>
    </div>

        <h2 id="syntax">CSS Syntax & Selectors</h2>
        <h3>CSS Rule Structure</h3>
        <p>A CSS rule consists of a selector and a declaration block. The declaration block contains one or more declarations separated by semicolons.<br> Each declaration includes a CSS property name and a value, separated by a colon.</p>
        <p><strong>selector { property: value; property: value; }</strong></p>
        <h3>CSS Selectors</h3>
        <h3>Element Selectors</h3>
        <p><strong> { color: blue; } p { font-size: 16px; }</strong></p>
        <h3>ID Selectors</h3>
        <p><strong>#header { background-color: #333; color: white; padding: 20px; }</strong></p>

        <h2 id="colors">Colors</h2>
        <h3>CSS Colors</h3>
        <p> Colors in CSS are used to give style to HTML elements. CSS supports several ways to specify colors including named colors, hexadecimal, RGB, RGBA, HSL, and HSLA values.</p>
        <h3>Color Names</h3>
        <p>CSS supports <mark>140</mark> named colors. These are simple to use but offer limited options</p>
        <p><strong>.red { color: red; } .blue { color: blue; } .green { color: green; } .purple { color: purple; }</strong></p>
        <h3>Hexadecimal Colors</h3>
        <p>Hex colors are specified with a # followed by 3 or 6 hexadecimal characters (0-9, A-F)</p>
        <h3>RGB Colors</h3>
        <p>RGB colors are specified with rgb() and three values from 0 to 255</p>
